# Asignación 01 — Fundamentos de C++

## Descripción

Esta asignación tiene como objetivo practicar los conceptos fundamentales de C++ vistos durante las primeras clases del curso u otros comunados u operaciones segun el nivel del estudiante.

Se implementaron diferentes funciones para trabajar con:

* Tipos de datos y variables.
* Operadores aritméticos, relacionales y lógicos.
* Estructuras de control.
* Funciones.
* Arreglos.
* Referencias.
* Punteros.
* Memoria dinámica.

## Ejercicios

### Ejercicio 1 — Calculadora básica

Implementación de operaciones de suma, resta, multiplicación y división.

### Ejercicio 2 — Conversión de temperatura

Conversión entre grados Celsius y Fahrenheit utilizando operaciones de punto flotante.

### Ejercicio 3 — Clasificación de números

Clasificación de números como positivos, negativos o cero, además de determinar si un número es positivo y par.

### Ejercicio 4 — Estadísticas de enteros

Cálculo de la suma de los números desde `1` hasta `n` y conteo de números pares mediante ciclos.

### Ejercicio 5 — Operaciones con arreglos

Implementación de funciones para calcular la suma, encontrar el máximo y verificar si un valor pertenece a un arreglo.

### Ejercicio 6 — Transformación de un arreglo

Multiplicación de todos los elementos de un arreglo por un factor determinado.

### Ejercicio 7 — División entera

Cálculo del cociente y residuo de una división entera utilizando referencias.

### Ejercicio 8 — Intercambio mediante punteros

Intercambio de los valores de dos variables utilizando punteros.

### Ejercicio 9 — Arreglo dinámico

Creación, inicialización y destrucción de un arreglo utilizando memoria dinámica mediante `new[]` y `delete[]`.

### Ejercicio 10 — Análisis de datos numéricos

Cálculo del promedio de un arreglo y conteo de los elementos que son mayores que un valor determinado.

## Compilación

Los ejercicios pueden compilarse individualmente utilizando `g++`. Por ejemplo:

```bash
g++ asignacion-01/ejercicio01/ejercicio01.cpp -o ejercicio01
./ejercicio01
```

El mismo procedimiento puede utilizarse para los demás ejercicios cambiando la ruta y el nombre del archivo.
